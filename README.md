## Troubleshooting Guide

### Nothing happens when the launcher starts

Make sure the complete download has been extracted. If you are using the source version, verify that the required Python environment, dependencies, and entry point are available by checking the project files.

### Mod installation fails

Confirm that the chosen files can be accessed and that the launcher is allowed to write to its working directories. Close other applications that may have the files open, then try the installation again.

### The new skin is not visible

Ensure the launcher completes the skin-related operation successfully and restart Minecraft if required. Any status messages or diagnostic information from the application may help identify the problem.

### A new build will not download

Test the network connection and retry the latest download link. If the problem remains, download a build manually or use the previously available release instead.

### Local files cannot be accessed

Place the application in a directory where your user account has the necessary permissions, then repeat setup. Do not remove local files until you have confirmed that they are no longer required.
